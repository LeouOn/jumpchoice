## Takeaway

The auto-tier is conservative on Combo Powers and Shardless / Multi-Pointer tracks. But the **most under-rated picks are cheap tier-3 durability picks** (Gomu Gomu, Phase, Target Acquired, Epilepsy, Knockout, Geas) and the **perk layer** (Trumped the Trump, All Seeing Precognition, Cloak II/III/IV).

The hidden gems cluster in:
1. **Cheap tier-3 durability** — best SP/value in the CYOA
2. **Perk layer** — overlooked entirely in v1
3. **Combo Powers** — trigger conditions hidden but real value
4. **Trump precog-blindspot clause** — under-emphasized in v1

If you're building a min-max, **don't trust the auto-tier for tier-3 durability picks**. They get 3 SP for Alexandria-tier immunity — that should be S-tier but the algorithm can't see narrative context.

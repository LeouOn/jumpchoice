## Per-combo 'how to use it right'

### Path to Victory

**Triggers**: Always-on

**Best use**: Universally. Plan ANY goal. PtV returns steps. **HAS BLINDSPOTS** (Eidolon, Trigger Events, Entities, Parts of Entities, Endbringers). Pair with **All Seeing Precognition** perk (20 SP + 10 CP) to remove blindspots.

**Synergies**: All Tier picks. PtV + Eidolon = 'figure out which 3 powers to slot.'

**Counters**: Blindspots (Eidolon, Entities, Endbringers, trigger events). PtV CANNOT path around these.

**How to use it right**: Phrase the goal specifically. 'I want to defeat X' is better than 'I want to win.' PtV returns steps. Execute them. For meta-threats (Entities, Endbringers), pair with All Seeing Precognition perk.

### ~~Khepri~~ (REMOVED — see Tier 3 Powers row)

**Khepri is NOT a Combo Power.** It is `(Master) Khepri` in the Tier 3 Powers row at 15 SP. See that row for full text.

### The Gamer

**Triggers**: Always-on (system layer)

**Best use**: Universal. Adds stats, levels, inventory, skills. Frames your entire build as a video game.

**Synergies**: Everything. Tinkers benefit from inventory. Brutes benefit from stats. Thinkers benefit from skills.

**Counters**: Anti-system effects (rare).

**How to use it right**: Use 'video game rules' liberally. Pause for crafting. Use inventory for storage. Stack XP.

### Dovahkiin

**Triggers**: Always-on (Thu'um magic)

**Best use**: Versatile magic. Slow Time, Fire Breath, Storm Call, Become Ethereal.

**Synergies**: All blaster / shaker. Pairs with The Gamer for skill-based Thu'um.

**Counters**: Silence effects. Anti-magic (rare).

**How to use it right**: Learn all 3 words of every shout. Slow Time + Become Ethereal = invincibility frames.

### Jedi Knight

**Triggers**: Always-on (Force + lightsaber)

**Best use**: Mid-range blaster / duelist. Slow Time, telekinesis, mind tricks.

**Synergies**: Blasters, Strikers, Movers. Pairs with Flechette/Foil for piercing lightsaber.

**Counters**: Ysalimiri (anti-Force, rare). EMP / force-dampeners.

**How to use it right**: Force push for crowd control. Force choke for non-lethal takedowns. Lightsaber for Brute-class enemies.

### Soldier of the Future

**Triggers**: Always-on (when using Tinkertech weapons)

**Best use**: Miss Militia + Tinkertech. Any weapon you've touched becomes a Miss Militia weapon.

**Synergies**: Armsmaster (Tinker), Bakuda (Tinker explosives), Miss Militia (Power Copy).

**Counters**: Tinkertech disruption. Distance from weapons.

**How to use it right**: Collect Tinkertech weapons. Use them all as Miss Militia weapons. You become a Tinker armory.

### Skittering Legions

**Triggers**: Always-on (control non-sapient life)

**Best use**: Skitter+1. Control any non-sapient life, not just arthropods.

**Synergies**: Skitter/Weaver (Power Copy), Khepri (Combo).

**Counters**: Fire. Anti-Master field. Non-biological attacks.

**How to use it right**: Use the full biosphere. Birds, mammals, fish, insects, anything. Pair with Skitter for full bio-dominion.

### Biobringer

**Triggers**: Always-on (carbon-based life control)

**Best use**: All biology. Panacea + Bonesaw + more.

**Synergies**: Bonesaw, Panacea, Bitch, Crawler, Skitter.

**Counters**: Non-biological attacks. Distance. Biological immunity.

**How to use it right**: Control all carbon-based life. Build a bioweapon. Heal allies. Resurrect the dead.

### Gate of Babylon

**Triggers**: Always-on (mythic treasure access)

**Best use**: Conceptual weapons, shields, reality marble. Pre-1900 mythic arsenal.

**Synergies**: All blaster, striker. Pairs with The Gamer (inventory).

**Counters**: Conceptual immunity (rare). Disarm.

**How to use it right**: Project Ea, Caladbolg, Gáe Bolg, etc. Reality marble for area denial.

### Golden Trio and their +1

**Triggers**: Time-loop (with party)

**Best use**: HP-style time loop with 3 others. Party-based time travel.

**Synergies**: Time Lord, Coil, time-related powers.

**Counters**: Anti-time-loop. Killing the +1.

**How to use it right**: Loop with your best 3 allies. HP-time-loop with party = unstoppable.

### The End-Becomer

**Triggers**: Always-on (control an existing Endbringer)

**Best use**: Take over an Endbringer. 10 SP.

**Synergies**: All Brute, all Shaker. Khepri (control capes).

**Counters**: Endbringer-killers (Slaughterhouse 9, Scion, Flechette).

**How to use it right**: Approach an Endbringer. Take control. You now command an Endbringer. 10 SP.

### Biotech

**Triggers**: Always-on (Tinkertech-to-bio conversion)

**Best use**: Convert any Tinkertech to a biological version.

**Synergies**: All Tinkers. Bonesaw, Panacea, bio-control stack.

**Counters**: Anti-Tinkertech.

**How to use it right**: Acquire Tinkertech. Convert to bio. Now you have bio-Tinkertech. Use it.

### Yang Xiao-Long

**Triggers**: Always-on (transform into Yang)

**Best use**: RWBY combat. Aura-amped. Semblance.

**Synergies**: All blaster, brute, striker. Pairs with Miss Militia (energy weapons).

**Counters**: Aura-breaker weapons. Semblance counter.

**How to use it right**: Transform into Yang. Aura absorbs hits. Semblance = punch-power storage. Ember Celica for ranged.

### Meta Knowledge

**Triggers**: When in a simulation

**Best use**: Detect simulation. Act differently or shut it down.

**Synergies**: All Thinker. Anti-Thinker (you know when you're simulated).

**Counters**: Real-world only. Can't break out of strong simulation.

**How to use it right**: Detect. Act. Break. Strong against PtV-style attacks (you know it's a path).

### Mage

**Triggers**: Always-on (magic that grows)

**Best use**: Trainable magic. Extensible.

**Synergies**: Dovahkiin, Jedi Knight, all magic users.

**Counters**: Anti-magic.

**How to use it right**: Train. Use. Stack with other magic for compound effect.

### Cabbage Corp

**Triggers**: Sabotage as long as it looks like an accident

**Best use**: Master/Stranger via plausible deniability.

**Synergies**: Cherish, Regent, Nice Guy. All social.

**Counters**: Video evidence. Thinker powers (Tattletale).

**How to use it right**: Cause 'accidents' for businesses. No consequences. Plausible deniability.

### Tsundere

**Triggers**: When hiding positive feelings

**Best use**: Social. Hiding affection grants UP-lite to the target.

**Synergies**: All romance-target powers. Nice Guy, Cherish.

**Counters**: Direct communication (no hiding needed).

**How to use it right**: Hide your feelings. Target gets UP-lite. Build relationships without admitting it.

### Avatar

**Triggers**: Always-on (all four elements + Energybending)

**Best use**: Avatar state. Full elemental control + energybending.

**Synergies**: All blaster, shaker, brute. Pairs with Tier 3 Last Airbender for compound.

**Counters**: Anti-Energybending. Bloodbender (moon-only).

**How to use it right**: Use all four elements. Energybend. Avatar state for K.O.

### Resurrection

**Triggers**: Repair corpse + use

**Best use**: Free Raise Dead. No memory loss, no brain damage.

**Synergies**: All allies, all resurrection-adjacent powers.

**Counters**: Soul-destroyed (no corpse).

**How to use it right**: Repair the corpse. Bring them back. No strings.

### Truth

**Triggers**: Throw them through a gate

**Best use**: Grant knowledge and any of your powers.

**Synergies**: All Trumps. Spreadable power.

**Counters**: Lore-only. The 'gate' mechanic is unclear.

**How to use it right**: Build a gate. Throw people through. They emerge with your power.

### Time Lord

**Triggers**: Always-on (Doctor Who time lord)

**Best use**: Time travel, TARDIS, regeneration.

**Synergies**: Coil, time-related.

**Counters**: Time-locked events.

**How to use it right**: Build a TARDIS. Travel. Regenerate on death (13 times).

### Biomass Generation

**Triggers**: Self-biokinesis

**Best use**: Self-biokinesis with no body-mass limit. Grow into a kaiju.

**Synergies**: Panacea, Bonesaw, all bio-control.

**Counters**: Mass-destruction attacks. Atomic-level dismantling.

**How to use it right**: Grow. Don't stop. Become a kaiju.

### The Legion of the Fae

**Triggers**: When you beat a Parahuman in battle

**Best use**: Permanent 50% copies of beaten capes. **Stacks with FQ.**

**Synergies**: Fairy Queen. Eidolon. The Gamer (storage).

**Counters**: Anti-Trump.

**How to use it right**: Fight. Win. Add 50% copy to your Legion. Repeat.

### Undertale

**Triggers**: Always-on (Undertale system)

**Best use**: SAVE, LOAD, RES, FIGHT, MERCY, ACT, ITEM. Be aware you're fictional.

**Synergies**: All time-loop. All roleplay-aware.

**Counters**: Author override. Plot armor.

**How to use it right**: SAVE often. LOAD on death. RES for non-violent. FIGHT when needed. ACT and ITEM for puzzles.

### Natsuki Subaru

**Triggers**: Transform into Subaru

**Best use**: Return by Death. Re:Zero kit. **-8 SP but SEVERE WITCH CURSE**: "Your heart will stop if you try to tell others of this ability... if you manage to tell them completely the Witch will kill them... You can not use the Witch too many times consecutively without repercussions... will make you smell like the Witch, which can be smelled by any Parahuman, Endbringer, animal, or entity, and will make them anything from wary to downright hostile."

**Synergies**: All time-loop. PtV (predict the loop).

**Counters**: Witch of Envy. Overuse. Telling anyone about your power (heart stops). Anyone you fully explain to (Witch kills them).

**How to use it right**: Get the checkpoint. Die strategically. Loop. Use knowledge. **NEVER tell anyone about your power.** Limit loop frequency or risk Witch hostility that makes everything (Parahumans, Endbringers, Entities) detect you.

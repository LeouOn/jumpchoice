# Worm CYOA V6.1 — Synergy Analysis

## How synergies are detected

Three signals:
1. **Worm canon knowledge** — pairs of capes/powers known to combo from the web serial.
2. **Combo Powers** — explicit game-mechanical pairings in the Combo Powers row.
3. **Tag overlap** — two choices with shared `tags` (defense/offense/mobility/etc.) or shared `powerClass`.

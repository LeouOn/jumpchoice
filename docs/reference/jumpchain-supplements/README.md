## Source quality and limitations

Each per-supplement analysis doc notes its source quality:

- **EBM (v1.13):** The provided HTML source is a partial v1.12 export. The analysis used the full v1.13 from Google Doc, cross-referenced against the HTML.
- **SBM (v1.2):** Full text from Google Doc. All costs and quoted text are verbatim.
- **PRS:** The source is a player's checklist, not the canonical PRS document. The analysis covers BASICS, UTILITIES AND STRUCTURES, and PERSONAL REALITY FACILITIES sections but not the full STRUCTURES catalog, MISC catalog, or full Utilities roster.
- **GFJ (v1.1):** Full Notion export. All 958 lines of perks analyzed.
- **UDS (v1.13):** Partial extraction. The first ~30 drawbacks (Chain Drawbacks + Jumper Drawbacks) plus the full rules framework are included. Warehouse Drawbacks, Companion Drawbacks, Power Drawbacks, Thematic Drawbacks, HQ Drawbacks, and others are NOT included. The Google Doc v1.13 (unreleased) is the most current version, ahead of the published v1.10.

**Implication for cross-supplement analysis:** The combined docs (tier list, builds, synergies, redteam) are based on partial information. The "Hate Squad → Vortex of Enemies" escalation in particular is speculative; the full UDS text would clarify.

## Currency

- **CP (Character Points)** — most jumps' base currency; supplements add CP via UDS Drawbacks
- **WP (Warehouse Points)** — PRS currency; 100 WP default, can be routed from UDS Warehouse Drawbacks
- **EP (Essence Points)** — EBM currency; 100 EP Standard, 500 EP Heroic, 0 EP Hardcore starting; +100 EP/jump Meteoric, +50/jump Heroic
- **JP (Jumper Points)** — game-specific currency from UDS Retail Rocker and other Drawbacks

## Quick reference: which supplement to take first

The canonical stacking order:

1. **UDS** — Chain Drawbacks first (always-active engine)
2. **GFJ** — first jump (bootstrap body mod budget)
3. **Body Mod** — EBM or SBM (your chassis)
4. **PRS** — warehouse + fortress
5. **Jump-specific perks** — per jump

See `combined-synergies.md` §7 for the full rationale.

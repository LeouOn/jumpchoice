## What this is

A post-apocalyptic SCP-universe CYOA. K-Day happened. The Foundation collapsed. You are a survivor building a new Guardian organization from the ruins. 8+ Major Projects, 15+ Minor Projects, 30+ Allies, 9 Lesser Conflicts, 8 Greater Conflicts, and 8 Drawbacks.

The setting is nobledark-to-nobelbright: the worst happened, but humanity is rebuilding. World population: ~182 million (2082). Hope exists, but the cosmic threats that ended the old world are still out there.

## Identity pick priority

**If you can pick a canon character with a Trump-class power, you can Power Copy someone ELSE.** Examples:
- **Taylor Hebert** (Skitter-style Master/Stranger, free in some sense) — but you have Skitter as Power Copy. Skip unless you want a Skitter-themed build.
- **Amy Dallon** (Panacea) — you can Power Copy Panacea, so skip unless you want the identity.
- **Lisa Wilbourn** (Tattletale) — same logic.
- **Dinah Alcott** (precog) — same logic.
- **An original character with a free drawback** — sometimes cheaper than a canon.

**Recommendation**: Pick an original character with a low/no cost, and use Power Copy for the canon.
